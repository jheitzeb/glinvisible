3. Make it a reflex

On a loaded webpage, press to toggle redaction. The page stays softly blurred during scanning, with a spinner and progress through visible text blocks. Scrolling and page changes trigger a fresh local scan.

For a saved HTML page, enable “Allow access to file URLs” in Chrome's extension details. Select text and use “Mask selection” in the extension popup to add a manual mask.

Visual concealment for screenshots and screen sharing. Original page data stays in the DOM. Models can miss information. Embedded frames, canvas and video are covered as whole regions; image text needs a manual mask. Model accuracy evaluation is pending.
